    What is Skillio?

    Skillio runs NVIDIA's SkillSpector over the things an agent is about to trust — an agent skill from a git URL, a folder or a .zip, or the whole MCP Registry — and keeps every report it produces.

    Instead of reading terminal output and trying to remember what you decided, you get a browsable log: findings grouped by severity, a re-scan flagged when it comes back different from the one you approved, and an install decision recorded against each one.

    Installing & upgrading SkillSpector

    Skillio doesn't bundle SkillSpector — it runs whatever skillspector it finds on your PATH. uv installs each command-line tool into its own isolated environment, so SkillSpector's dependencies can't collide with anything else on your machine, and leaves a small shim at ~/.local/bin/skillspector that never moves.

    Install it

    uv tool install git+https://github.com/NVIDIA/skillspector.git

    Needs uv itself first. Skillio never installs anything on your behalf — you run these yourself, in a terminal.

    Upgrade it

    uv tool upgrade skillspector

    Re-resolves SkillSpector from the same source and rebuilds that isolated environment in place. It was installed from git with no pinned version, so this takes whatever is on the default branch — usually the release named above, occasionally a little ahead of it. The shim path doesn't change, so Skillio keeps finding it.

    Afterwards

    Your scan log is never touched by either command — it lives in Skillio's own database, separately. Once the command finishes, use Check for updates again: Skillio re-reads the installed version rather than trusting what it saw last.

    If it still isn't found

    skillspector has to be on the PATH of the process running Skillio, which is not always your shell's. A launchd background service inherits nothing from your terminal — it carries its own PATH, written when you installed it. If you installed SkillSpector after setting up that service, re-run ./macos/install-service.sh so the agent picks up the new location.
