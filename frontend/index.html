Off — static analysis only: about 20 analyzers matching patterns, parsing code and tracing tainted data. Takes seconds, costs nothing.

On — adds 3 semantic analyzers that read the skill and judge whether what it does matches what it says. That's the only thing which catches instructions hidden in SKILL.md prose, since prose has no code signature. Takes 30–90s and spends your LLM provider's quota.

Needs SKILLSPECTOR_PROVIDER set. Without it the scan quietly falls back to static — the result page will tell you when that happens.
